# Sim Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An automated pytest suite that boots a headless TurtleBot3 Nav2 sim, drives the real `Nav2ConfigNode` and `MainWindow` against it, checks every README feature including real navigation, and runs on every push in CI.

**Architecture:** `test/sim/` holds session fixtures (`sim_stack`, `app`) plus small helpers; one test module per feature area, all marked `sim` and deselected by default. A separate `sim-test.yaml` workflow runs `pytest -m sim` on Humble in parallel with the existing `ci.yaml`. The `ros2` CLI is used only as an independent oracle and as the restore path.

**Tech Stack:** pytest, PyQt6 (offscreen), rclpy, nav2_bringup `tb3_simulation_launch.py`, `nav2_simple_commander`, GitHub Actions + `ros-tooling/setup-ros@v0.7`.

**Spec:** `docs/superpowers/specs/2026-11-23-sim-test-design.md`

## Global Constraints

- Humble only, `ubuntu-22.04`; no Jazzy, no namespaced or multi-robot stacks.
- Sim launch: `ros2 launch nav2_bringup tb3_simulation_launch.py headless:=True use_rviz:=False`, env `TURTLEBOT3_MODEL=waffle`, `GAZEBO_MODEL_DATABASE_URI=""`.
- Sim start budget 120 s; on timeout kill the process group and retry the launch **once**; then fail with the log tail. Never retry the whole job or a failing test.
- Teardown: SIGINT the process group, then SIGKILL, then sweep stray `gzserver`/`gzclient`.
- No fixed `sleep` in tests; use `wait_until`.
- Every test that changes a live param restores it, even when an assertion fails.
- `sim` marker registered in `setup.cfg`; default runs use `-m "not sim"`.
- Known bugs (`restart_node` / `restart_controller` no-op) are `xfail(strict=True)`, not fixed.
- Workflow: triggers push+PR on `main`/`master` and `workflow_dispatch`; `concurrency` cancels older runs of the same ref; `timeout-minutes: 30`; failure uploads sim stdout and `~/.ros/log`.
- Local run command: `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 QT_QPA_PLATFORM=offscreen python3 -m pytest -m sim test/sim -v`.
- Do not commit anything until the user says so; commit steps below apply once they have.

## Review Focus

1. Sim fails to come up: fixture retries once, then fails with the log tail, not a hang.
2. Test or Ctrl+C aborts mid-run: no `gzserver`/`gzclient` survives, no live param left changed.
3. Setting an invalid value or a nonexistent param returns failure through the tool, never hangs or crashes the GUI.
4. Schema lists a node that is not running (e.g. `docking_server`): the live schema check skips it, does not fail.
5. Array param round trip including an empty list, and a param whose type differs from the schema.

### Task 1: Harness, marker, and discovery

**Files:**

- Create: `test/sim/__init__.py` (empty), `test/sim/helpers.py`, `test/sim/conftest.py`
- Create: `test/test_sim_harness.py` (not marked `sim`; runs in normal CI)
- Create: `test/sim/test_discovery.py`

**Interfaces:**
- Produces in `helpers.py`:
  - `wait_until(cond: Callable[[], bool], timeout: float = 30.0, interval: float = 0.1, what: str = "condition") -> None`: pumps `QCoreApplication.processEvents()` between polls; raises `TimeoutError(f"timed out waiting for {what}")`.
  - `ros2_param_get(node: str, name: str) -> str` and `ros2_param_set(node: str, name: str, value: str) -> int` (CLI, returns rc).
  - `class SignalRecorder: __init__(self, signal)`, `.calls: list[tuple]`, `.wait(n: int = 1, timeout: float = 15.0) -> list[tuple]`.
  - `start_stack(cmd: list[str], ready: Callable[[], bool], timeout: float, retries: int, log_path: Path, env: dict | None = None) -> subprocess.Popen`: starts `cmd` with `start_new_session=True`, waits for `ready()`, on timeout kills the group and retries up to `retries` more times, then raises `RuntimeError` including the last 40 log lines.
  - `stop_stack(proc: subprocess.Popen) -> None`: SIGINT group, wait 10 s, SIGKILL group, then `pkill -9 gzserver`/`gzclient`.
- Produces in `conftest.py` (all session scope unless noted):
  - fixture `sim_stack() -> Path` (yields the sim log path): uses `start_stack` with the Global Constraints command; `ready` = every node in `ros2 lifecycle nodes` reports `active` and `/amcl_pose` has a message after the initial pose is set via `nav2_simple_commander.BasicNavigator.setInitialPose`.
  - fixture `app(sim_stack) -> App` where `App` is a dataclass `(node: Nav2ConfigNode, window: MainWindow, schema: list[Nav2ParamDef])`. Wiring copied from `nav2_config/main.py` steps 1-5 (rclpy init, `MultiThreadedExecutor` thread, `load_schema`, `QApplication`, `MainWindow(node)`), torn down in reverse.
  - fixture `restore_params()` (function scope) yielding `touch(node: str, name: str) -> None`; records the current CLI value now and restores it in the finalizer via `ros2_param_set`.
